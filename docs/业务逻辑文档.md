# AI学习助手 - 业务逻辑文档

## 一、产品定位

### 1.1 核心洞察

**用户痛点**：收藏了100篇文章，真正读完的可能只有5篇。"收藏 = 学会了"是最大的自欺欺人。

**真实需求**：不是"收集更多"，而是"消化已收集的"。用户需要的是帮助理解和内化知识的工具。

### 1.2 产品定位

**一句话描述**：AI学习助手 - 帮你把"收藏"变成"学会"

**核心价值**：
- 一键总结：快速理解文章核心观点
- 智能问答：基于收藏内容回答问题
- 知识卡片：生成可复习的知识卡片
- 学习追踪：记录学习进度，提醒复习

### 1.3 目标用户

| 用户群体 | 痛点场景 | 核心需求 |
|---------|---------|---------|
| 考研党 | 资料太多看不完，看了记不住 | 高效消化知识点，考前复习 |
| 考证党 | 知识点散落各处，难以系统化 | 整理知识体系，重点标记 |
| 职场学习者 | 学习时间碎片化，学了就忘 | 快速理解，定期复习 |
| 自我提升者 | 收藏了大量文章但没时间看 | 一键获取精华，高效学习 |

### 1.4 差异化优势

| 竞品 | 定位 | 我们的差异 |
|------|------|-----------|
| 微信收藏 | 收藏工具 | 我们是学习工具，帮用户消化内容 |
| Notion | 知识管理 | 我们聚焦"学习消化"，AI能力更强 |
| 印象笔记 | 笔记工具 | 我们提供智能总结和问答 |
| 得到 | 知识付费 | 用户自己的内容，更个性化 |

### 2.2 核心功能详解

#### 功能一：一键总结（核心卖点）

**用户场景**：用户收藏了一篇长文章，没时间细读，想快速了解核心内容。

**功能流程**：
1. 用户选择一篇内容
2. 点击"AI总结"按钮
3. 系统调用AI生成：
   - 核心观点（3-5条）
   - 关键概念解释
   - 行动建议（如适用）
   - 一句话精华
4. 用户可以保存总结到知识卡片

**AI提示词设计**：
```
请对以下内容进行深度总结：

【原文内容】
{content}

请按以下格式输出：
## 核心观点
1. ...
2. ...
3. ...

## 关键概念
- 概念1：解释
- 概念2：解释

## 行动建议
1. ...
2. ...

## 一句话精华
（用一句话概括全文精华）
```

#### 功能二：智能问答

**用户场景**：用户想针对收藏的内容提问，深入理解某个知识点。

**功能流程**：
1. 用户在内容详情页输入问题
2. 系统基于当前内容和用户的其他相关知识进行回答
3. 支持追问和深入讨论

**AI提示词设计**：
```
你是一个专业的学习助手。请基于以下知识内容回答用户的问题。

【相关知识点】
{relatedContent}

【用户问题】
{question}

请提供准确、有深度的回答，必要时引用原文内容。
```

#### 功能三：知识卡片生成

**用户场景**：用户想把长文章压缩成可复习的知识卡片。

**功能流程**：
1. 用户选择内容，点击"生成知识卡片"
2. AI提取关键知识点，生成卡片格式
3. 卡片支持翻转查看（正面问题，背面答案）
4. 支持添加到复习计划

**卡片格式**：
```json
{
  "id": "card-001",
  "title": "什么是React Hooks？",
  "front": "React Hooks是什么？它解决了什么问题？",
  "back": "React Hooks是React 16.8引入的新特性，允许在函数组件中使用状态和其他React特性。它解决了类组件的this绑定问题、逻辑复用困难等问题。",
  "source": "React Hooks使用指南",
  "createdAt": "2024-01-20",
  "reviewCount": 0,
  "nextReview": "2024-01-21"
}
```

#### 功能四：学习追踪

**用户场景**：用户想了解自己的学习进度，获得复习提醒。

**功能流程**：
1. 系统自动统计：
   - 总内容数 vs 已学习数
   - 本周学习时长
   - 知识卡片复习次数
2. 基于艾宾浩斯遗忘曲线提醒复习
3. 生成周学习报告

## 三、数据结构设计

### 3.1 核心数据模型

```typescript
// 学习内容
interface LearningItem {
  id: string;
  title: string;
  content: string;           // 原文内容
  summary?: string;          // AI总结
  keyPoints?: string[];      // 核心观点
  source: 'link' | 'text' | 'pdf' | 'manual';
  sourceUrl?: string;
  tags: string[];
  category: string;
  
  // 学习状态
  status: 'unread' | 'reading' | 'mastered';
  readProgress: number;      // 阅读进度 0-100
  lastReadAt?: Date;
  
  // AI生成内容
  knowledgeCards: KnowledgeCard[];
  questions: Question[];
  
  // 时间戳
  createdAt: Date;
  updatedAt: Date;
  userId: string;
}

// 知识卡片
interface KnowledgeCard {
  id: string;
  itemId: string;
  front: string;             // 正面（问题）
  back: string;              // 背面（答案）
  difficulty: 'easy' | 'medium' | 'hard';
  
  // 复习相关
  reviewCount: number;
  lastReviewAt?: Date;
  nextReviewAt: Date;        // 下次复习时间
  easeFactor: number;        // 记忆难度因子
  
  createdAt: Date;
}

// 学习记录
interface LearningRecord {
  id: string;
  itemId: string;
  action: 'view' | 'summarize' | 'quiz' | 'review';
  duration: number;          // 学习时长（秒）
  createdAt: Date;
  userId: string;
}

// 学习统计
interface LearningStats {
  totalItems: number;
  readItems: number;
  masteredItems: number;
  totalCards: number;
  reviewedCards: number;
  weeklyStudyTime: number;   // 本周学习时长（分钟）
  streak: number;            // 连续学习天数
}

// 用户设置
interface UserSettings {
  dailyGoal: number;         // 每日学习目标（分钟）
  reminderTime: string;      // 提醒时间
  preferredSummaryLength: 'brief' | 'medium' | 'detailed';
  darkMode: boolean;
}
```

### 3.2 状态管理

```typescript
interface AppState {

  // 学习内容

  learningRecords: LearningRecord[];

  // 分类标签
  categories: string[];
```

## 六、技术实现要点

### 6.1 AI能力集成

- **文本总结**：DeepSeek API
- **智能问答**：DeepSeek API（带上下文）
- **知识卡片生成**：DeepSeek API（结构化输出）

### 6.2 数据持久化

- 使用LocalStorage存储用户数据
- 支持数据导出/导入
- 预留云端同步接口

### 6.3 复习算法

- 基于SM-2算法（Anki使用的算法）
- 根据用户反馈调整复习间隔
- 支持手动调整难度

## 九、风险与应对

### 9.1 技术风险

| 风险 | 应对措施 |
|------|---------|
| API成本过高 | 限制免费用户使用次数，优化提示词长度 |
| 内容抓取失败 | 提供文本粘贴备选方案，引导用户手动输入 |

### 9.2 竞争风险

| 风险 | 应对措施 |
|------|---------|
| 大厂入局 | 聚焦细分场景，做深做透 |
| 功能被抄袭 | 持续迭代，建立用户粘性 |
