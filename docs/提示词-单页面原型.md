# AI学习助手 - 单页面应用原型提示词

## 项目背景

我正在开发一个"AI学习助手"应用，帮助用户把"收藏"变成"学会"。核心功能是AI一键总结、智能问答、知识卡片生成和学习追踪。

请帮我创建一个单页面应用原型，用于快速验证产品核心价值。

---

## 技术栈要求

- **框架**：React 18 + TypeScript
- **构建工具**：Vite
- **样式**：TailwindCSS
- **状态管理**：React Context + useReducer
- **路由**：React Router（单页面可不用）
- **数据持久化**：LocalStorage
- **AI接口**：DeepSeek API（用于总结、问答）

---

## 核心功能需求

### 1. 内容导入区（左侧）

**功能**：
- 链接输入框：用户粘贴文章链接
- 文本输入框：用户直接粘贴文本内容
- 导入按钮：点击后保存内容

**交互**：
- 导入成功后显示成功提示
- 内容自动添加到右侧内容列表

### 2. AI学习中心（中间核心区域）

**功能**：
- 显示当前选中内容的原文
- "AI总结"按钮：点击后调用API生成总结
- 总结结果展示区：
  - 核心观点（3-5条）
  - 关键概念
  - 一句话精华
- "生成知识卡片"按钮：将总结转为卡片格式

**交互**：
- 点击AI总结时显示loading状态
- 总结结果支持复制
- 知识卡片支持翻转查看

### 3. 内容列表区（右侧）

**功能**：
- 显示所有导入的内容
- 每条内容显示：标题、来源、学习状态、导入时间
- 支持筛选：全部/未学/学习中/已掌握
- 点击内容项在中间区域显示详情

**学习状态**：
- 未读（灰色）
- 学习中（蓝色）
- 已掌握（绿色）

### 4. 知识卡片区（底部/可折叠）

**功能**：
- 显示所有生成的知识卡片
- 卡片正面显示问题，点击翻转显示答案
- "开始复习"按钮：进入复习模式

**复习模式**：
- 随机展示卡片
- 用户自评：简单/一般/困难
- 根据评分调整下次复习时间

### 5. 学习统计（顶部）

**功能**：
- 总内容数
- 已学习数
- 知识卡片数
- 今日学习时长

## AI API调用示例

### DeepSeek API配置

```typescript
const DEEPSEEK_API_KEY = 'your-api-key';
const DEEPSEEK_API_URL = 'https://api.deepseek.com/v1/chat/completions';

// 调用AI总结
async function summarizeContent(content: string): Promise<string> {
  const response = await fetch(DEEPSEEK_API_URL, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': `Bearer ${DEEPSEEK_API_KEY}`
    },
    body: JSON.stringify({
      model: 'deepseek-chat',
      messages: [
        {
          role: 'system',
          content: '你是一个专业的学习助手，擅长总结和提炼知识要点。'
        },
        {
          role: 'user',
          content: `请对以下内容进行深度总结，提取核心观点（3-5条）和关键概念，并用一句话概括精华：\n\n${content}`
        }
      ],
      max_tokens: 1000,
      temperature: 0.7
    })
  });
  
  const data = await response.json();
  return data.choices[0].message.content;
}
```
